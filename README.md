# Bank CSV Export Helper Privacy Policy

This folder is ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a new public GitHub repository, for example:
   `bank-csv-export-helper-privacy`
2. Upload `index.html` to the root of the repository.
3. In the repository, go to **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
5. Save.
6. GitHub will show the public Pages URL after deployment.

Your privacy-policy URL will usually look like:

`https://YOUR-USERNAME.github.io/bank-csv-export-helper-privacy/`

Use that full URL in the Chrome Web Store **Privacy policy URL** field.
