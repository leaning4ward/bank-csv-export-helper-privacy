Bank CSV Export Helper Privacy Policy

Effective date: September 4, 2026

Bank CSV Export Helper is a Chrome extension that helps users export transaction CSV files from supported banking websites and save those downloads with consistent, identifiable filenames.

Data handling

The extension does not upload banking information, transaction data, authentication credentials, or downloaded CSV file contents to the developer or to external servers.

The extension may temporarily process limited information within the browser that is necessary to complete a user-requested export workflow, such as the selected year, navigation state, and an account identifier used to create a filename. This information remains local to the browser and is used only to perform the requested export.

Downloaded CSV files

The extension does not read, copy, transmit, or store the contents of downloaded CSV files. It uses Chrome's download functionality only to assign a consistent filename to a download initiated by the user.

Website access

The extension requests access only to supported Chase, Capital One, and Wells Fargo websites so it can interact with their transaction/export pages as part of the user-initiated workflow.

Remote code, analytics, and advertising

The extension does not load or execute remotely hosted code. It does not use analytics trackers, advertising trackers, or behavioral advertising.

Sale or transfer of data

The extension does not sell user data. It does not transfer user data to third parties for advertising, lending, creditworthiness, or unrelated purposes.

Data retention

Temporary workflow information is stored only as needed to complete the export process and is not retained as a transaction-history database by the extension.

Changes to this policy

If the extension's data practices change, this privacy policy will be updated to reflect those changes.

Contact

For privacy questions, use the support contact provided on the Bank CSV Export Helper Chrome Web Store listing.
